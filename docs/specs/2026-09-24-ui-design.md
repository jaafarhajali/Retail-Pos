# Retail POS — UI design tokens (2026-09-24)

Subject: an argile / hookah shop — charcoal, brass, enamel tobacco tins, molasses. Two audiences:
the owner on a laptop (admin pages) and a cashier on a touch terminal (POS).

**Colour**
- `--paper #F2F3F1` cool stone page ground · `--surface #FFFFFF` · `--ink #1B1F24` · `--ink-2 #5B6470` · `--line #DDE1E4`
- `--accent #1F6E8C` enamel-tin blue (links, primary buttons, active nav) · `--amber #B7791F` low stock, warnings · `--green #2E7D4F` · `--red #B3261E`
- POS: `--pos-bg #15181C`, `--pos-surface #1F2429`, `--pos-line #2C333A`, `--pos-ink #F3F4F6`, `--ember #D9622B` — used **only** for the amount due and the Pay action.

**Type** — one family: the Windows system UI face (`Segoe UI Variable` → `Segoe UI` → system-ui), which also
sets Arabic. Scale 13 / 14 / 16 / 20 / 26 / 34, weights 400 / 600. Every money and quantity figure is
`font-variant-numeric: tabular-nums`. Totals on the till: 34 px / 600.

**Layout** — sidebar 232 px (slate `#20262D`), content left-aligned, max 1280 px. Page title is the first
line of the content, not a separate bar. Tables and forms sit on white surfaces with a 1 px line; no
shadows, no card-in-card. Inputs 44 px; POS controls 56 px. Category tiles use the category colour as a
left edge, not a filled block.

**Principles** — the numbers are the voice; everything else is quiet. One bold element per screen (the
POS amount due). Sentence case, plain verbs on buttons ("Save product", "Take payment"), no eyebrow
labels, no decorative motion; only state changes animate.
