# Retail POS — UI design tokens (2026-09-24, revised the same day)

Subject: an argile / hookah shop — charcoal, brass stems, enamel tobacco tins, the paper receipt. Two audiences:
the owner on a laptop (admin pages) and a cashier on a touch terminal (the till, 1024×768).

**Colour**
- Admin: `--stone #EDF0F1` page ground · `--surface #FFFFFF` · `--ink #14222C` · `--ink-2 #53636F` · `--line #D3DADE`
- `--enamel #17587A` enamel-tin blue (links, primary buttons, focus) · `--enamel-deep #0E2A3A` (sidebar, sign-in)
- `--brass #D9A441` / till `#E0AC48` — **money to collect**: the till's amount due, Take payment, Complete sale, the
  change on the done screen. In the admin it appears only as the brand mark and the active-menu marker.
- Status: `--green #2B7A4B` · `--amber #93600E` (low stock, warnings) · `--red #B3261E`, each with a soft tint for badges and alerts.
- Till: counter `#0F2331`, panels `#142C3B`, raised `#1A3748`, lines `#26485B`, ink `#EEF4F7`; the sale itself is a
  **paper ticket** `#FBFCFC` with dark ink, so the lines read at arm's length.
- Changed from the first plan: the till is no longer near-black with an orange "ember" accent (a generic dark-UI look,
  and the orange sat next to the category colours) — it is deep enamel with brass, and the ticket is paper.

**Type** — the Windows system face in its optical cuts: `Segoe UI Variable Display` for headings and big figures,
`Segoe UI Variable Text` for body, `Segoe UI Variable Small` for table heads and help text (fallback `Segoe UI`, which
also sets Arabic). Scale 12 / 13.5 / 15 / 17 / 24 / 36 / 50 px, weights 400 / 600 / 700. Every money and quantity
figure is `tabular-nums`. Codes (P-000001, INV-000012) are tabular sans in a quiet chip, not monospace.

**Layout**
- Admin: sidebar 232 px, grouped — Dashboard and Till on top, then Selling, Stock, Money; Administration is folded
  unless one of its pages is open, so the menu fits 768 px. Header: page title, the exchange-rate chip, Open the till,
  the user menu (password, sign out). Content left-aligned, max 1320 px. White panels with a 1 px line, no shadows;
  filter bars are one quiet strip above the table. Below 800 px the menu folds behind a Menu button.
- Till: a station strip (shop, register, session, cashier; Session / Sales / Returns / Exit) over two panes. Left: the
  scanner field (light, 60 px, brass focus ring — always the most visible control), category tabs with colour
  swatches, product tiles with the category colour as a left edge. Right: customer and price level, the paper ticket
  (quantity block, name, unit price, line total), the due block with the brass USD figure and the LBP figure, then
  four 62 px actions and a 66 px Take payment.
- Till dialogs have an on-screen keypad that types into the last number field touched; the payment dialog opens
  with Exact USD / Exact LBP / Add payment and shows Change or Still due in large type. The done screen shows the
  change at 67 px.
- Receipts: 72 mm (80 mm paper) or 52 mm, black on white, TOTAL and its LBP line in bold, no colour.

**Principles** — the numbers are the voice; everything else is quiet. One bold element per screen (on the till:
the brass amount due; it turns grey while the cart is empty). Touch targets on the till are 56 px or more.
Sentence case, plain verbs on buttons ("Save product", "Take payment"), no eyebrow labels, no decorative motion;
only state changes animate. Arabic names keep `dir="auto"` but line up left in table columns.
